# Contribuer à Block World

Merci de votre intérêt ! Toute aide est la bienvenue — tester le jeu et signaler ce qui cloche est déjà une vraie contribution.

## Tester le jeu

1. **Installez Godot 4.7.1** (version standard, pas « .NET ») depuis [godotengine.org](https://godotengine.org/fr/download/) ou Steam. Le projet n'est pas testé avec d'autres versions.
2. **Récupérez le projet** : bouton vert « Code » → « Download ZIP » sur [la page GitHub](https://github.com/PawsAndPlayForever/Block-World), ou bien :
   ```
   git clone https://github.com/PawsAndPlayForever/Block-World.git
   ```
3. **Ouvrez-le** : lancez Godot, cliquez « Importer », sélectionnez le fichier `project.godot` du dossier.
4. **Lancez le jeu** avec `F5` (ou le bouton ▶ en haut à droite).

## Signaler un bug

Ouvrez une [issue GitHub](https://github.com/PawsAndPlayForever/Block-World/issues) avec :

- ce que vous faisiez et ce qui s'est passé (vs. ce que vous attendiez) ;
- une capture d'écran si le problème est visuel ;
- les messages du panneau « Sortie » en bas de l'éditeur Godot, s'il y en a en rouge ;
- votre système (Windows/Linux/macOS) et votre carte graphique.

Même un simple « ça rame chez moi » avec la config de votre machine est une information utile.

## Proposer une amélioration

- **Discutez d'abord** : pour tout changement non trivial, ouvrez une issue avant de coder, histoire de ne pas travailler pour rien.
- **Par où commencer** : la section « Ligne de route » du [README](README.md) liste ce qui est prévu ; les issues ouvertes listent ce qui est cassé.
- **Envoyez une pull request** : fork du dépôt → branche dédiée → PR. Une PR = un sujet ; les petites PR sont relues vite, les grosses traînent.

## Une question ?

Ouvrez une issue, même juste pour demander comment quelque chose fonctionne. Ce projet sert aussi à apprendre — il n'y a pas de question bête.
