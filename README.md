# Création d'un jeu vidéo (Block World) sur Godot 4.7.1

Petit projet réalisé avec le moteur de jeu [**Godot**](https://godotengine.org/fr/). Projet initialement lancé grâce à **Claude**.

## Gameplay

Il s'agit d'un Action-RPG cubique. Plus tard, j'aimerais ajouter la possibilité de jouer en multijoueur, dévelloper le système de classe en proposant plusieurs compétences actives et passives, retravailler les personnages crées par Claude, améliorer la *QOL* et optimiser le jeu.
