# Création d'un jeu vidéo (Block World) sur Godot 4.7.1

Petit projet réalisé avec le moteur de jeu [**Godot**](https://godotengine.org/fr/). Projet initialement lancé grâce à **Claude**.

## Gameplay

Il s'agit d'un Action-RPG cubique. Plus tard, j'aimerais ajouter la possibilité de jouer en multijoueur, dévelloper le système de classe en proposant plusieurs compétences actives et passives, retravailler les personnages crées par Claude et améliorer la *QOL*

## Ligne de route

- Amélioration graphique du jeu vidéo
    - Création d'un personnage pour chaque classe
    - Création d'une texture pour les objets
    - Création des ennemies
- Ajout d'un système de niveau
- Ajout de compétences passives et actives liés aux classes
- Possibilité de casser, exploiter et placer les cubes
- Ajout du mode multijoueur
- (Optionnel) Améliorer la qualité de vie et optimisation du jeu
